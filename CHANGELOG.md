# Changelog

Every release is published under [Releases](https://github.com/JackWorld99/shuttle/releases); an installed Shuttle checks for updates on its own.
Versions are the date plus a build number, e.g. `2026.11.21 (2289)`. Release pages carry the notes in both English and Chinese.

Shuttle is based on [LocalSend](https://github.com/localsend/localsend) 1.18.2; see its repository for LocalSend's own history.

| Build | Date | Changes |
|---|---|---|
| 2303 | 2026-11-22 | Source code published; updates now come from this repository and are signed with a new key, so install this version once by hand (auto-update resumes afterwards). On the computer, new installs follow the system language; the Windows installer is in English and Chinese; the drop zone shows the name from "My devices"; clearer English wording |
| 2289 | 2026-11-21 | Only verified devices are auto-accepted; faster hashing before sending; media saved straight to the gallery on Android 10+; Android now uses a release signing key (uninstall the old build once); small UI fixes |
| 2283 | 2026-11-21 | "My devices" and pairing records no longer overwrite each other when changed at the same time |
| 2281 | 2026-11-20 | Shares ask before sending; settings recover from a backup and history no longer drops entries; safer pairing; optional start at sign-in |
| 2276 | 2026-11-20 | Update right from Settings → More after checking |
| 2275 | 2026-11-20 | Better detection of installed copies; pairing records note the method; diagnostics log on Windows |
| 2274 | 2026-11-18 | Updates no longer wait for another running Shuttle; a failed update reopens the old one |
| 2273 | 2026-11-18 | More reliable hand-over to the installer after the download |
| 2272 | 2026-11-18 | The version is shown in full; includes the macOS changes |
| 2268 | 2026-11-16 | Faster update downloads; the new version line shows the build number |
| 2267 | 2026-11-16 | First version that updates itself |
